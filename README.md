# Formline

A demo poster store built as a static Next.js export. Orders are not real and nothing is charged.

## Run it

### Development

```bash
pnpm install
pnpm dev
```

### Static preview

```bash
pnpm build && pnpm preview
```

Served on port 4321.

## Tests

```bash
pnpm test
```
