# Security Policy

This is a demo storefront running Stripe in test mode. It keeps no order database of its own. On the card-payment path your order lines and the email you type go to the checkout function and on to Stripe's test mode, where they stay with the checkout session; your name and address stay in your browser.

If you find a security issue, report it privately through the contact details on https://sopilnik.dev — never in a public issue.

GitHub's private vulnerability reporting form on this repository's Security tab works as well.

Expect a reply within five working days.

This project does not run a bug bounty.
